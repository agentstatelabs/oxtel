# Code of Conduct

oxtel follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Everyone taking part in the project, in issues, pull requests, discussions and any other project space, is expected to follow it.

## Reporting

Report unacceptable behaviour to the maintainers at **info@agentstatelabs.com**. Every report is reviewed and investigated promptly and fairly, and the reporter's privacy is respected.

Maintainers who don't follow or enforce the Code of Conduct may face consequences decided by the project's other maintainers. Enforcement follows the Covenant's [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).

## Attribution

This Code of Conduct adopts the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1, by reference.
