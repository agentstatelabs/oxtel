## Choices

Everything here is set from the environment, so it can change without a rebuild:

| Setting | What it does |
|---|---|
| `RUST_LOG` | how much is logged: `info` (the default), `debug`, `warn`, or per module, such as `info,hyper=warn` |
| `OXTEL_LOG_FORMAT` | `auto` (the default: text on a terminal, JSON otherwise), `text`, `json`, `ecs` (Elastic Common Schema) or `none` |
| `OXTEL_LOG_OUTPUT` | `stderr` (the default) or `stdout` |

## For production

- JSON is already the default anywhere that isn't a terminal, such as a container or a service manager.
- Keep the value `oxtel::init()` returns until `main` ends. Log lines are written as they happen, so for them it makes no difference; once you send telemetry somewhere, dropping it at the end of `main` is what sends the last batch.
